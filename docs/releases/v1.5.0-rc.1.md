# NowShowing TV 1.5.0-rc.1

TV remote usability and release-packaging candidate. Android build **15001**.

## What's improved
- Cleaner playback controls: Open player / Return to video, Change source, Episodes, Retry, and Back to title.
- First-use remote tips, repeatable help, and a pointer that appears when entering the player.
- Precise short arrow taps and accelerated held movement, including touch forwarding to provider fullscreen views.
- Back exits fullscreen before opening app controls; title navigation is explicit.
- Current season, episode number, episode title when available, and selected-source/episode markers.
- Native demo videos moved to Settings > Playback diagnostics.
- App version and build number visible in Settings; larger player controls and supporting text.
- Includes progressive home shelves, bounded shared metadata caching, browsing position/focus restoration, and local Recently opened from the preceding polish pass.

## Downloads
Use **NowShowing-TV-1.5.0-rc.1-release.apk** for normal TV sideloading. The debug APK is for development. SHA256SUMS.txt, SIGNING-CERTIFICATES.txt, and build-info.json identify the exact build.

## Validation and limitations
CI runs JVM regression tests, release-script tests, and debug/release APK builds. Prior web-provider playback was confirmed on the owner's TV; new remote/menu behavior still needs real-device verification. Providers retain their own seek/subtitle/resume behavior. The app does not claim measured iframe progress or automatic completion.

Read [installation/update guidance](https://github.com/smile-plzz/NowShowing-Stream-Android-TV/blob/main/docs/INSTALLATION.md), [known limitations](https://github.com/smile-plzz/NowShowing-Stream-Android-TV/blob/main/docs/KNOWN_LIMITATIONS.md), and [troubleshooting](https://github.com/smile-plzz/NowShowing-Stream-Android-TV/blob/main/docs/TROUBLESHOOTING.md).

**Upgrade carefully:** a different signing certificate prevents an in-place update. Uninstalling deletes local data. Permanent signing setup is documented separately.
