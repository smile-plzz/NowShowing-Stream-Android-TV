# NowShowing TV 1.5.0

Android version code **15003**. Polished standalone Android TV sideload release.

## What changed
- All 1.5.0-rc.2 metadata, watched-label, filter-update, focus, episode, cache and diagnostics fixes.
- Scrollable navigation that keeps every destination reachable on narrower TV layouts, with clearer selected/focused tabs.
- Settings organized into Playback, Metadata, Privacy, Help and About; larger supporting text and consistent action feedback.
- Readable diagnostic report dialog with remote scrolling and focus restoration. Exports wait for a generated report.
- Explicit personal-key saving and Use demo key action. Blank fields cannot accidentally erase a saved key.
- Retry/settings recovery for empty Browse; useful Mood failure states and cancellation of superseded requests.
- Player loading feedback and first-use hints that hide after eight seconds. Remote help remains available.
- Static AsyncImage poster loading/error states, avoiding subcomposition for each lazy-grid poster.
- Compose UI regressions and release integrity tests. Publisher checks both APKs, checksums, certificate report, version/code, exact commit and signing/prerelease policy before creating the release.

## Installation
Download **NowShowing-TV-1.5.0-release.apk**. The debug variant is for troubleshooting. SHA256SUMS.txt, SIGNING-CERTIFICATES.txt and build-info.json identify the exact downloads. Compare the certificate with your current installation before updating. A mismatch prevents an in-place upgrade; uninstalling erases local data.

## Playback and validation boundaries
Current web providers still require **manual Next episode**. The persisted autoplay setting defaults on but only acts where verified completion is supported. No web timestamp resume or completion-driven movie panel is claimed. Cached related titles remain on Details.

CI gates publication on JVM/Robolectric/Compose and release-script tests, debug/minified-release assembly, APK signature verification and packaging. Real-provider playback, remote usability, same-certificate upgrades and long-session performance on the owner's TV remain device checks; see docs/TV_ACCEPTANCE.md. No new physical-TV profiling was performed for this release.

If development-signed, this release is explicitly marked **Prerelease**. That preserves honest signing status rather than claiming a permanent production identity. No private keystore is committed or included in downloads.
