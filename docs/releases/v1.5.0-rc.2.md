# NowShowing TV 1.5.0-rc.2

Android version code **15002**. Candidate preparation; publication is separate from a successful PR build.

## Changes
- Structured metadata quota/key/network/service/no-results handling; bounded retry circuit, optional personal key, deduplicated search/season requests, stale fallback and capped persistent metadata/search history.
- Manual title-level Watched survives reopening. Cache clearing preserves saved user data.
- Play enters providers directly; Details defaults focus to Play and return focus participates in lifecycle restoration. Provider-required play clicks remain possible.
- Prominent manual Next episode, metadata-based season boundaries and default-on persisted autoplay preference. Current web providers still lack verified completion integration; no automatic web advancement is claimed.
- Lightweight genre-related cached titles; fewer sequential Home shelves, lower network concurrency, bounded decoded-image memory and reduced poster effects.
- About, build/device/WebView/certificate/cache diagnostics, safe recent metadata errors and copy/share/visible report.
- Correct Android filter URLs, bounded validation, atomic per-list replacement, response closure and accurate complete/partial/failure results.
- Updated active documentation and focused JVM/Robolectric regressions.

## Validation and signing
See the PR/build run and release bundle's build-info.json for the exact commit and signing mode. This document does not assert CI success or device performance. PR artifacts are development signed; stable signing continuity and same-certificate update checks remain required. Private signing material is never committed.
