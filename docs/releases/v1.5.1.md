# NowShowing TV 1.5.1

- Settings → Metadata accepts up to five masked, local OMDb credentials separated by commas or spaces, deduplicated in order. Existing single-key preferences remain compatible.
- Invalid/inactive credentials fall back automatically, bounded to the configured list. Rejected keys stay skipped until Retry or configuration changes. Network, service, quota and genuine no-results failures never cycle keys.
- Successful/fresh caches and bounded stale fallback remain available across credential failures. Diagnostics retain safe error categories only.
- Personal credentials are not embedded in public APKs or committed. Configure them on each TV. No automatic rotation to multiply free quotas; OMDb lists 1,000 daily requests for free credentials and restricts circumventing usage limits.

Validation: repository, credential parser/selection and TV Settings regressions run through the gated build workflow, alongside debug/release assemblies and packaging verification. Refer to the linked run for actual results. Device and provider playback validation remains pending; WebView playback is unchanged.

Development-signing fallback remains a prerelease. Check the release certificate report before updating; certificate continuity with a previously installed APK is not established.
