# NowShowing TV 1.6.0-rc.2

Android version code: 16001. This is a sideload testing candidate.

## Daily-use improvements
- Type directly into the title field with the Android system keyboard, including supported hardware/remote keyboards; the existing D-pad keyboard remains available.
- Search controls scroll on shorter TV viewports. Results show the submitted title and loaded/total count.
- Watchlist offers movie/series filters, recent/title/release-year ordering and Find titles. Sorting and filtering use local saved data without metadata requests.
- Includes the rc.1 progressive cached browsing, bounded metadata loading, genre/year discovery, photo-friendly app health reports, About updates and demo removal.

## Installation and acceptance
Compare the APK certificate with the installed app before attempting an upgrade. The previously reported installed certificate is
22:AA:2A:F5:98:20:E0:03:E4:51:FF:B3:0F:26:42:50:66:76:41:FC:21:00:40:98:79:8E:B6:93:44:0E:B3:52.
Development builds have a different certificate and cannot update that installation. Do not uninstall the installed app as a workaround: local watchlists and history could be lost.

A permanent key alone does not prove continuity; it must match the installed certificate. Stable release remains gated on compatible signing and real-TV acceptance. Test keyboard availability, D-pad focus/return behavior, library sorting, browsing responsiveness, report photography and provider playback. Web autoplay remains dependent on provider completion support; manual Next episode is available.

See [Signing](../RELEASE_SIGNING.md), [TV acceptance](../TV_ACCEPTANCE.md), and [App health](../APP_HEALTH.md).

## Side-by-side TV testing
The `-debug.apk` download installs as **NowShowing Preview** (`com.nowshowing.tv.preview`), with separate local storage. Use this candidate to test alongside the existing NowShowing TV installation. Preview starts with its own empty watchlist/history/settings and does not migrate the installed app's data. The `-release.apk` retains `com.nowshowing.tv` and requires a matching certificate for an in-place upgrade. Preview is a debug test build; its performance is not evidence of minified release performance.
