# 1.6.0-rc.5 (16004) — Physical remote media keys, voice search, update checker, and privacy hardening

Version code: 16004. Candidate; real-TV acceptance pending.

- **Physical Remote Media Keys**: Intercept hardware media buttons (`KEYCODE_MEDIA_PLAY_PAUSE`, `KEYCODE_MEDIA_PLAY`, `KEYCODE_MEDIA_PAUSE`, `KEYCODE_MEDIA_FAST_FORWARD`, `KEYCODE_MEDIA_REWIND`) in web embed playback, injecting guarded JavaScript targeting `<video>` elements with ±10s seeking and graceful no-ops.
- **1-Click Next Source**: Instant provider cycler in `SourceRegistry` preserving IMDb ID, season, and episode, accessible from the web player controls drawer and via `KEYCODE_MEDIA_NEXT` on physical remotes, with top-center TV HUD notification.
- **Voice Search**: Added a focusable TV microphone button in `SearchScreen` launching Android system speech recognition (`ACTION_RECOGNIZE_SPEECH`) with graceful fallback if speech engines are unavailable.
- **GitHub Releases Update Checker**: Integrated `UpdateChecker` in `SettingsScreen` (About) comparing `BuildConfig.VERSION_NAME` against the latest GitHub release tag with semver evaluation and release note modal dialog.
- **Deceptive Ad & QR Overlay Removal**: Injected idempotent MutationObserver DOM sweeper for deceptive QR bot-verification overlays, hard-blocked verified hostile redirect networks, pruned speculative domains, moved generic web push services to user-configurable filters, and dropped broad keyword patterns.
- **Crash Recovery & Cloud Catalog**: WebView renderer crash recovery with explicit retry/change-source actions, dedicated candidates for all 29 moods, and validated cloud catalog ingestion.
- **Comprehensive Unit Testing**: 158 unit tests passing across 39 test suites (100% green), including 17 new regression tests for media keys, source advance, update checking, and network filtering.
