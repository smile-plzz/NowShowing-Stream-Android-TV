# NowShowing TV 1.6.0-rc.4

Version code: 16003. Daily-use reliability candidate, including the previously merged rc.3 mood and related-title refinements.

- Search retries keep earlier pages when Load more fails.
- Episode lists show loading and offer Retry episodes on failure.
- Switching titles clears old player and episode state.
- Watchlist updates avoid overlapping toggles and stale refreshes.
- Search/watchlist return focus uses stable title IDs.

The build workflow runs all JVM tests and produces debug and minified release APKs. Seven new regression tests cover the changes; eight Python packaging/integrity checks protect the bundle.

## Install and test
Use the debug APK (**NowShowing Preview**) to test beside your installed app, with separate data. The release APK uses the original package name and requires a matching signing certificate to upgrade. Inspect the bundled signing report before replacing an existing installation.

Run the [candidate TV checks](../DAILY_USE_ASSESSMENT.md). Physical-TV smoothness and live-provider playback have not been verified in this pass. Web episodes still require manual Next episode, and provider ads/progress limitations remain unchanged.
